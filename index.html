🔥 Hubungkan Cloud Database (Firebase)

Dengan menghubungkan Firebase Firestore (gratis dari Google), seluruh HP tim OMK (H-1 dan Hari-H) akan tersinkronisasi secara otomatis dan realtime.

Status Firebase Saat Ini: Belum Terhubung
ℹ️ Cara Mudah Mendapatkan Firebase Gratis (3 Menit):
  1. Buka console.firebase.google.com dan login akun Google.
  2. Klik "Add Project" (Beri nama misal Kantin OMK YGP).
  3. Pilih "Build" ➔ "Firestore Database" ➔ Klik "Create Database" (Pilih mode Test Mode).
  4. Klik icon Web (</>) di Project Overview untuk mendaftarkan web app, lalu salin objek firebaseConfig ke kotak di atas!
